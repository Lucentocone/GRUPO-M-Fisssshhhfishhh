# Project.md

## 1. Objetivo del sistema
Desarrollar una aplicación web para la organización y gestión de eventos académicos.

---

## 2. Alcance
El sistema permitirá:
- Crear y gestionar eventos
- Inscribir participantes
- Gestionar roles (organizador, participante, disertante)
- Generar certificados
- Generar reportes

---

## 3. Tipo de sistema
Aplicación web accesible desde cualquier dispositivo con conexión a internet.

---

## 4. Roles del sistema
- Organizador
- Participante
- Disertante
